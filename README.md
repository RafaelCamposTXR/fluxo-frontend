# Fluxo

Este projeto é um aplicativo web front-end desenvolvido com Angular para gerenciamento de tarefas. O objetivo principal do projeto é fornecer uma interface simples e intuitiva para visualizar e gerenciar uma lista de tarefas.

## Funcionalidades

-   **Visualização de Tarefas**: Exibe uma lista de tarefas com detalhes como título, descrição, data de vencimento e status.
-   **Alternar Status**: Permite que o usuário mude o status de uma tarefa entre "concluída" e "pendente".
-   **Roteamento**: A página inicial do aplicativo é configurada para redirecionar automaticamente para a lista de tarefas.

O projeto foi gerado com [Angular CLI](https://github.com/angular/angular-cli) versão 15.2.11.
